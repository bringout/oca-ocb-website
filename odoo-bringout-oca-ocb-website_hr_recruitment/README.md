# Online Jobs

This module allows to publish your available job positions on your website and keep track of application submissions easily.

## Installation

```bash
pip install odoo-bringout-oca-ocb-website_hr_recruitment
```

## Dependencies

- hr_recruitment
- website_mail

## Source
