# Send SMS to Visitor

Allows to send sms to website visitor if the visitor is linked to a partner.

## Installation

```bash
pip install odoo-bringout-oca-ocb-website_sms
```

## Dependencies

- website
- sms

## Source

- Repository: https://github.com/OCA/OCB
