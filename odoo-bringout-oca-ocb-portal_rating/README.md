# Portal Rating


Bridge module adding rating capabilities on portal. It includes notably
inclusion of rating directly within the customer portal discuss widget.
        

## Installation

```bash
pip install odoo-bringout-oca-ocb-portal_rating
```

## Dependencies

- portal
- rating
